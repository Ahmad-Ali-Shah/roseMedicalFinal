# Homepage hero source selection

The four current homepage banner masters are the monochrome user-provided surgical-instrument banners supplied during the compact-homepage refinement. The earlier `home-hero/v1` blue operating-room images are historical assets and are not the current client-selected banner set.

Production requirement: desktop and mobile derivatives must be real locally hosted raster files. Do not use raster-in-SVG wrappers and do not relabel encoded AVIF/JPEG bytes with a `.webp` filename.
